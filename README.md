### Inspiration
The original idea for this theme came from [Eva](https://github.com/eva20040424). Unfortunately, there was never an official repository for it. Most of the work was done locally and never pushed to GitHub, which is completely understandable for a personal project. Because of that, only parts of the original theme are still around, and some pieces have been lost over time.

This project continues where the original left off. I've filled in views and classes that weren't styled, updated the remaining global variables to match the overall design, and polished the rough edges to make the theme feel more complete—all while trying to stay as close as possible to Eva's original vision.
